# 评审与边界

## 审计一致性

- 六个案例来自公开聚合中精确的 `required_fact_missing` 集合，不由人工挑样；11 条命题来自
  固定私有集的原顺序，未改题、未改期望。
- 每条命题同时列出 approved clause、obligation 与 claim；公开 JSON 另存冻结事实、客户可见
  投影和支撑 span 的 SHA-256，能发现输入或抄录漂移，但不公开明文。
- `SCQ-002/P2` 明确保留跨 claim 上下文组合，不把单个“本次”脱离前文误判为独立覆盖。
- 六题结论均为字面假阴性，所以没有用“部分抽样”外推；若任何一题缺完整语义，计数必须改为
  真遗漏，且不能提出对六题统一消码。

## 方案边界

- 候选方案只改变未来 Stage 12 评分层的 R6 证据形态，不改变 product / generation / prompt /
  API / outcome；本切片没有实现该方案。
- proposition receipt 复用 ADR-0007 的责任分工：模型负责语义声明，host 只核对 ID、范围和
  完整性。它比字面子串与现行生成合同一致，但不是开放域语义 judge。
- `required_proposition_binding_missing` 只拟表示“规划存在但没有合法 claim 收据”；它不能把
  合法 ID 下的错误语义声明自动识别为遗漏，人工最终决定仍是安全底线。
- 不改变今夜 24/24、11 通过和 14 码历史，不产生重评分结果或发布结论。
