# 未见集检索首次观测

## Goal

在 `night-20260802` 上冻结 10 题公开合成未见集及其独立评测知识，随后只执行一次现有
BM25、Local BGE 与 RRF 的离线检索观测，落盘来源覆盖与错误型号来源；观察后把该版本降为
只读回归资产，不针对结果调整检索、问题、标签或知识。

## Non-goals

- 不运行生成、产品工作流、Provider、凭据、费用或外部业务写入。
- 不把评测知识加入生产语料，不改变检索实现、参数、模型、产品 API 或公开发布主张。
- 不用揭示后的结果调参、改题、削弱标签或替换知识，不重复执行“首次观测”。
- 不转 Ready、不合并 `main`、不部署；只更新既有 Draft PR #62。

## AC

1. **WHEN** 运行结构校验，**THEN** 恰有 10 题、CZ-R1 / CZ-R2 各 5 题、问题与标签唯一，
   且每个标签都指向同型号的独立评测知识单元。
2. **WHEN** 校验未见边界，**THEN** 对现有 16 题开发集的问题规范化全文、来源引用和生产知识
   单元规范化全文分别报告 0 个重复，且 16 个新知识单元全部被标签覆盖。
3. **WHEN** 首次排名开始，**THEN** Git 中已有包含题目、标签、知识和冻结纪律的前置提交；
   观测文件记录该完整 freeze commit 与题集 SHA-256，并拒绝覆盖既有观测。
4. **WHEN** 首次观测完成，**THEN** BM25、BGE、RRF 分别落盘 Top-5 / Top-10 全标签覆盖题数、
   逐题必需来源名次和 Top-10 错误型号来源数。
5. **WHEN** 审查执行面，**THEN** Provider 调用 0、生成调用 0、评测知识未进入产品语料，现有
   检索实现和参数无差异。
6. **WHEN** 运行相关测试、API 全集、治理和公开仓检查，**THEN** 现有合同全绿；新测试只校验
   冻结结构与已落盘回执，不在 CI 中重新跑首次观测。
7. **WHEN** 候选交付，**THEN** 更新并推送 `night-20260802` 的既有 Draft PR #62，确认最终
   head 的 required Checks 已启动；不转 Ready、不合并、不部署。

## 验证说明卡

- **问题**：冻结后，现有 BM25 / Local BGE / RRF 对 10 个未见问题能否在 Top-5 / Top-10
  找全人工标注来源，并保持错误型号来源为 0？
- **最便宜证伪**：冻结前只运行结构与零重复校验；形成前置提交后，唯一一次运行本地检索工具。
- **固定资产**：`evals/retrieval-holdout-v1.json` 的题目、标签、16 个评测知识单元及其字节哈希。
- **固定执行**：型号过滤在排序前，Top K=10，当前产品 BM25 合同、固定本地 BGE 模型与 RRF；
  Provider / generation 均为 0，自动重试 0。
- **允许结论**：只说明该冻结合成未见集的来源覆盖与错误型号来源观察值。
- **禁止结论**：不说明回答正确率、生成质量、线上成功率、真实用户泛化或发布成熟度。
- **停止线**：首次结果无论好坏都停止检索改动；发现结构、重复、模型托管或绑定失败则不排名，
  直接停手写战报。
