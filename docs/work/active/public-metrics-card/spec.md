# 公开数字口径卡

## Goal

在 `night-20260802` 上新增一页公开数字口径卡，把当前公开的产品结果、评测结果与运行约束
逐项绑定定义、测量方法、数据集 / 对象、单次 / 可复跑属性、仓库证据和否定边界，使数字在
面试追问中可解释、可回查且不互相冒充。

## Non-goals

- 不新增、重算或美化任何数字，不运行正式评测、Provider 或产品 run。
- 不修改产品代码、检索、生成、评测资产、Workflow、依赖、生产配置或公开页面。
- 不把日期、版本、SHA、端口、Issue / PR 编号和阅读导航标签包装成产品指标。
- 不转 Ready、不合并 `main`、不部署；只更新既有 Draft PR #62。

## AC

1. **WHEN** 阅读 `docs/product/metrics-card.md`，**THEN** 指定的检索开发集、Stage 12、
   生成门、HOLDOUT、pgvector、预算与队列数字均有独立卡片。
2. **WHEN** 审查任一卡片，**THEN** 都能找到数字、定义、测量方法、数据集 / 对象、
   单次 / 可复跑、证据、边界 / 不是什么七类字段。
3. **WHEN** 校验开发集数字，**THEN** 基线与候选 JSON 精确给出 BM25 14→15/16、BGE
   14/16、RRF 16/16、三路 Top-10 16/16、错误型号 0，不推导未见集改善。
4. **WHEN** 校验历史与未见结果，**THEN** Stage 12 的 19/24、9、停止原因与 10 题 HOLDOUT
   的 10/10、零重复、零 Provider / generation 均与机器结果一致，二者不混用。
5. **WHEN** 校验 pgvector 与控制面，**THEN** JSON 时间 / 覆盖值和 `runs.py` 的预算、队列、
   浏览器、输入、留存常量均与口径卡逐项一致。
6. **WHEN** 遍历卡片中的仓库相对链接，**THEN** 每个证据文件均存在；外部链接只用于固定
   GitHub run，不替代仓库证据文件。
7. **WHEN** 运行治理全集、公开仓扫描、文档园丁与差异检查，**THEN** 全部通过或仅保留既有
   非阻断 review；Git diff 中没有产品代码、评测资产或 Workflow 变化。
8. **WHEN** 交付候选，**THEN** 推送 `night-20260802` 并更新 Draft PR #62，确认最终 head
   required Checks 全绿；不转 Ready、不合并、不部署。

## 验证说明卡

- **问题**：口径卡中的每个数字能否从已有机器结果、代码常量或固定运行回执独立复核，且
  没有把开发集、未见集、一次运行、默认配置和线上质量混为一谈？
- **最便宜证伪**：用只读脚本加载现有 JSON / Python 常量，检查卡片的必需字段、数字字面量
  与相对链接；不重跑任何正式结果。
- **固定输入**：当前分支已有的 baseline / candidate / HOLDOUT / pgvector / Stage 12 结果、
  ADR-0007、控制面常量与固定 CI run。
- **允许结论**：已有数字现在有统一、可回查的解释入口。
- **禁止结论**：任何数字获得了新样本、新质量含义、线上代表性或发布成熟度。
- **停止线**：证据间出现冲突时保留待确认并停止该数字，不用重跑评测或改代码补齐。
