# 评审与边界

## 当前方案判断

- 复用现有 SQLite 与单实例锁比新增监控服务更符合本切片：不增加部署面和依赖，聚合表行数由
  路由 / 方法 / 错误类别固定上界约束。
- 统一 ASGI 外层可以覆盖成功、路由错误和未形成响应的 transport 失败；规范化路由避免把
  `run_id` 或未知原始路径写入数据库。
- 观测端点自身不计数，使其保持语义上的只读；这意味着返回值刻意不包含观测读取流量。
- 同步 SQLite 聚合写是单机 Beta 的有界折中；本切片不宣称高吞吐、跨实例一致性或 SLA。
