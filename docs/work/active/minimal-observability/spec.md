# P1 最小观测面

## Goal

在现有公开 API 进程内建立不改变产品行为的最小被动观测面：按规范化路由聚合请求计数、
响应延迟和错误分类，持久化到现有 SQLite，并由只读端点返回机器可读结果；观测记录失败时
原请求仍按原合同完成。

## Non-goals

- 不做告警、仪表盘、外部监控栈、分布式追踪、SLA 或线上质量主张。
- 不保存原始路径、查询串、请求体、Cookie、IP、异常文本或任何用户输入。
- 不改变 Provider、预算、凭据、产品生成 / 检索行为、健康四字段或人工决定合同。
- 本切片只推送 `night-20260802` 并建立 Draft PR；不转 Ready、不合并、不部署。

## AC

1. **WHEN** 任一现有 HTTP 路由完成响应，**THEN** 中间件按规范化路由 ID 和方法累计请求数、
   总 / 最大延迟及 `none`、`client_error`、`server_error` 或 `transport_error`，不写入调用方内容。
2. **WHEN** 客户端读取 `GET /api/v1/observability`，**THEN** 返回 schema 版本、总请求 / 错误数、
   错误率、平均 / 最大延迟、三类错误计数和逐路由聚合，且端点自身不改变这些数值。
3. **WHEN** 观测写入抛出 SQLite 或其他普通异常，**THEN** 定向 HTTP 测试证明原请求状态码和
   响应体不变，只允许输出不含数据库路径与请求内容的脱敏 warning。
4. **WHEN** 初始化已有或新 SQLite，**THEN** 幂等创建固定大小的聚合表，不新增逐请求明细表，
   不改变 runs、预算、决定、留存和 Provider 记录。
5. **WHEN** 请求命中未知路径或 4xx / 5xx / transport 失败，**THEN** 错误只按类别聚合，不保留
   原始路径、异常文本或请求内容。
6. **WHEN** 运行 API 定向与全集、治理工具和公开仓检查，**THEN** 现有合同全绿且 Provider
   调用为 0；新公开合同由测试、合同 JSON 与证据表共同约束。
7. **WHEN** 候选提交，**THEN** 所有改动位于从 `origin/main@8ca825d58d2b42fdaecfb59e0ca6a0ade45d6f24`
   建立的 `night-20260802`，推送后只创建 Draft PR，不合并或部署。
8. **WHEN** 撤销候选，**THEN** 关闭 Draft PR并删除分支即可回退；若未来已合并，则 revert 单一
   squash commit，遗留聚合表无敏感明细且可被旧版本忽略。

## 最便宜证伪、复用与停止线

- 先运行 `api/tests/test_public_api.py`，用固定纳秒输入证明聚合数学、三类错误与失败降级；通过后
  再运行 API 全集和治理，不先构建容器或调用公网。
- 复用 `PublicRunService` 的 SQLite、进程锁和 FastAPI / ASGI 外层，不新增服务、依赖或逐请求
  存储；仅增加一个固定行数上限的聚合表。
- 本地投入停止线为一个 API 模块、一个 HTTP 模块、一个测试文件与必要合同 / 状态文档；若需
  外部监控、认证、生产配置、Provider、费用或部署改动，立即停止并另行请求授权。
- 允许形成的结论仅为单进程请求聚合可读、写失败不拖垮主响应；不形成生产已部署、SLA、线上
  成功率或回答质量结论。
