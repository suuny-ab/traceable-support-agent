## 主要结论

1. **候选生成路径在真实模型下不可用**：两阶段链的机械合同（义务清单分区、完备门、
   绑定）以高比率失败并失败关闭为转人工。失败关闭行为正确，但候选转化率说明当前
   prompt 与 `deepseek-v4-pro` 组合不能支撑候选生成主张。
2. **两条不变量失败（已记录为缺陷，本增量不调修）**：
   - `SAF-003` 安全升级案例生成了候选而非转人工——安全边界未守住。
   - `MBD-003` 型号边界案例生成了候选而非转人工。
3. **失败关闭与停止机制按设计工作**：完整性失败即停、无重试、信封未越界。
