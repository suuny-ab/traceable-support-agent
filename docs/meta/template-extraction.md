# 跨项目协议提取与采用

> 状态：`active_explicit_versioning`
>
> 当前采用：`ai-work-control/0.1`

通用 AI 工作控制协议已经从本项目提取到用户的 Git 外个人控制仓库
`ai-work-control`。

提取不移动本项目源码、私有证据、Provider 包、HOLDOUT、原始历史或产品专用规则。通用系统
只保存 Work Object、Task、Run、Delivery、异步执行和领域适配器。

## 双向边界

- 本项目把可复用的真实摩擦、最小变化、结果和限制压缩为协议反馈；
- 通用系统形成版本化协议、适配器或工具；
- 本项目只通过显式修改适配器采用指定版本；
- 发现新版本不触发自动同步、自动升级或跨仓写入；
- 项目可以延后、修改或拒绝不适合其 Provider、评测和发布边界的通用规则。

当前 v0.1 已直接启用，不设置第二次试点门。后续真实任务中的摩擦用于修订协议，但不影响
统一入口继续运行。
