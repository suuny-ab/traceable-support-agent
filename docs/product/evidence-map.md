| --- | --- | --- |
| 四页作品集可以公开访问 | `/`、`/design`、`/app`、`/privacy` 的 HTTPS 冒烟检查 | 不证明最终视觉设计已经完成 |
| Provider 关闭时，公开服务会失败关闭 | API 集成测试和容器健康检查 | 不证明实时 Provider 的质量 |

主页、简历或 README 中的每项新增主张，都必须在本表中绑定代码、测试或运行证据。未知或未执行的主张继续标记为 `未验证`。
