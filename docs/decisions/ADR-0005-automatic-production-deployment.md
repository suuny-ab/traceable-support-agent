# ADR-0005：绿色主线自动生产部署

> 状态：已采纳
> 日期：`2026-07-23`

## 背景

ADR-0004 为首次迁移保留逐次人工批准。真实生产演练现已在提交 `f5dbcb7` 上完成
`旧 → 新 → 旧 → 新`，正式回执、容器健康、公网健康和用户体验验收均通过。用户明确判断
逐次批准不提供额外决策价值，并授予绿色 `main` 常设自动生产部署权限。

## 决定

`main` 的 `ci-release` 全部成功后，`deploy-production` 自动读取对应不可变发布清单并进入
生产，不再要求 GitHub environment required reviewer。`production` environment 继续只接受
受保护分支，production secrets 继续只在部署 job 内可用。

删除人工门不删除技术门：来源必须是同仓 `main` push 的成功运行；清单继续绑定 run ID、
Git SHA 和 attempt；镜像使用摘要；可信控制器执行哈希和 SSH 输入预检；Provider 保持关闭；
本地/公网健康、`旧 → 新 → 旧 → 新`、状态补偿和最终回执继续失败关闭。手动调度只作为恢复
入口，但预检同样核验同仓 `ci-release`、push、`main`、成功结论、SHA、attempt 和唯一未
过期制品。缺少 decision 的兼容范围固定为已经验证的旧成功 run `29999870811`；其他 run
失败关闭。手动路径与自动路径共享清单、健康和回滚门。

## 后果

合并到受保护 `main` 即包含生产发布意图；后续不会再有第二次“是否部署”的人工确认。
失败部署不会自动重跑，现网按补偿合同保留或恢复到已验证版本。发布运行名称显示来源
`ci-release` ID，便于追踪。该决定不授权 Provider、费用、敏感数据或外部业务动作，也不
形成高可用或 SLA 主张。
